# Lay the foundation

## Problem

This web app is the template's own first commit and nothing in it belongs to anybody yet: it has a name nobody chose, a screen nobody asked for, and no proof that the pathway from an ask to a witnessed attempt works at all on this copy.

## Description

Make the first thing that is yours. Name the product where it says its own name, and let the attempt that does it go the whole way round: an agent writes it, CI runs the checks the template already carries and publishes what ran, and what it did lands on the record beside this requirement. Nothing here is scaffolding to delete later — it is the first witnessed change.

## Acceptance criteria

- A fresh copy installs, and its tests pass — the check foundation > installs and tests
- The app starts and shows its name on its first screen — the check foundation > first screen, and CI takes a picture of it
- DoneMark can read this project: its tests report back, and you can start a build — a fact from the reporter, not a check
